# Peaseblossom's documents

What each document is for and who it is for. Using poc needs only the
first group; the rest is for working on poc. `make doc` makes the first
two groups as HTML and PDF, in `build/doc`; a release tarball has them in
`html/` and `pdf/` here. `make install`, and so each package, installs only
the first group's.

## For users: writing programs with poc

| Document | What it is |
|---|---|
| `users-guide.md` | The User's Guide: installing poc, building programs, modules, libraries, failures, debugging, calling C, the runtime modules, coming from voc. Start here. |
| `reference-guide.md` | The Reference Guide: exactly what poc accepts and does - the basic types, the extensions, `SYSTEM`, constants and arithmetic, traps, the command line, file formats, and every runtime module's interface. |
| `poc.1` | The manual page: every command and option. |
| `examples/` | The User's Guide's examples, run by the test suite (`tools/guide-examples`). |

`../README.md` introduces the project, and `../INSTALL.md` says how to
build and install it.

## Research behind decisions (`research/`)

Records of what other Oberons and systems do, written to decide something.
They say what was true when they were written; the decision itself is in
the developer documents or `../PLAN.md`.

| Document | What it is |
|---|---|
| `research/array-assignment-survey.md` | Assigning strings and character arrays in other Oberons (Phase 11, A21). |
| `research/assert-survey.md` | `ASSERT` in other Oberons (Phase 11, A14). |
| `research/overflow-survey.md` | Overflow, underflow and division in other Oberons (Phase 11, C5). |
| `research/truncating-division-survey.md` | Truncated integer division and remainder in the Oberons, Modula-2 and Modula-3 (Phase 19, `QUOT` and `REM`). |

| `research/shared-library-versioning.md` | Background: shared library versioning on Linux and the three BSDs. |
