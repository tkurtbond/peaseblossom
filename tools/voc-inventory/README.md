# voc-inventory

Generates the tables of `doc/voc-module-inventory.md` (PLAN.md Phase 12
step 3): one row for each of the 161 `.Mod` files of Vishap Oberon's
runtime, libraries and tools.

    make build
    tools/voc-inventory/inventory

The script rewrites everything in the document after the line
`<!-- Generated by tools/voc-inventory/inventory: ... -->`. The prose
above that line, including the findings, is written by hand. Reread it
when the tables change. The script needs `python3`, which of the
development machines only atla has. `VOC_SOURCE` and `VOC_INSTALL`
override where voc's source clone and install are; the defaults are the
paths `AGENTS.md` gives.

| File | What it does |
|---|---|
| `inventory` | The driver. It checks each library and runtime module with `build/bin/poc -O2 -emit-interface`, in import order, in a scratch directory. That directory holds poc-rtl's `.sym` files, so voc's `Files`, `Platform`, ... are replaced by poc's own, as a program would get them. It then writes the tables into the document. |
| `voc_sources.py` | Reads voc's sources: each module's name, imports and size, its inline C (`PROCEDURE -`), and whether voc's makefile builds it and voc's install has its `.sym`. It also defines which of a module's variants (`Platformunix`, `oocCLP64`) this host uses. |
| `extract_modules.py` | Writes what `voc_sources.py` reads, as JSON. |
| `import_order.py` | Lists the modules, each after its imports. |
| `write_tables.py` | Writes the Markdown tables. |
| `module_purposes.py` | The *Purpose* column, written by hand from each module's source. |

Kept by hand, and to update when things change:

- `module_purposes.py`, for a module voc adds;
- in `write_tables.py`:
  - `IN_POC`, what `rtl/llvm` has of voc's runtime modules;
  - `EXPLANATIONS`, what a module's first error means when the message
    alone does not say. A failure not listed there shows poc's message.
